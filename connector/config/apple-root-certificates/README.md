# Pinned Apple root certificates

Downloaded from [Apple PKI](https://www.apple.com/certificateauthority/) on
2026-10-08. These are public trust anchors, not application signing keys.
The DER files are unmodified Apple-issued certificates. `HostedBilling` validates
these SHA-256 file hashes before constructing Apple's `SignedDataVerifier`:

The library verifies chain signatures, certificate validity and Apple-specific
certificate purpose OIDs. Hosted verification enables online OCSP revocation
checks. Including a root does not bypass its expiry or the chain checks. Update
trust anchors only from Apple's official PKI distribution, review the new
fingerprints and change the code pins in the same reviewed update. Never replace
these files with the certificates generated by the test suite.

Apple's [Node library documentation](https://github.com/apple/app-store-server-library-node#obtaining-apple-root-certificates)
directs integrators to obtain trust anchors from that Apple PKI section.
